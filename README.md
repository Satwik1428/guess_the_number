# Mini Project – Guess the Number 

A fun and interactive **number guessing game** built using **HTML, CSS, and JavaScript**, created to **practice DOM manipulation concepts**.

---

##  Description
This mini project is designed to practice JavaScript DOM manipulation.  
The computer generates a random number between 1 and 100, and the user tries to guess the correct number within a limited number of attempts.

After each guess, the application updates the UI dynamically to indicate whether the guessed number is "too high" or "too low", making it a hands on DOM practice project.

---

##  Features
- Random number generation between 1 and 100
- User input handling
- DOM-based feedback messages (Too High / Too Low)
- Limited number of attempts
- Display of previous guesses
- Beginner friendly DOM interactions

---

## Technologies Used
- HTML
- CSS
- JavaScript (**DOM Manipulation**)
